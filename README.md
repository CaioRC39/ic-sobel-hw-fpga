# SystemVerilog Template

Template pronto com Dev Container para desenvolvimento em SystemVerilog.

## Como usar
1. Clone este repositório
2. Abra a pasta no VS Code
3. Ctrl+Shift+P → Dev Containers: Reopen in Container
4. Use `make help` para ver os comandos

Ferramentas incluídas: Icarus, Verilator, Verible, GTKWave, cocotb.
